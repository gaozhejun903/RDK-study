# Task05｜Nav2 自主导航

## 目标
```text
目标点 → 定位 → 全局规划 → 局部避障 → /cmd_vel → 到达
```

## 1. 前置地图
确保存在：
```text
~/maps/rdk_study_map.yaml
~/maps/rdk_study_map.pgm
```

## 2. 启动 Gazebo
```bash
export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py
```

## 3. 启动 Navigation2
```bash
export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_navigation2 navigation2.launch.py use_sim_time:=True map:=$HOME/maps/rdk_study_map.yaml
```

## 4. RViz 设置初始位姿
点击 **2D Pose Estimate**，在地图上点机器人真实位置并拖出朝向。

## 5. 发送目标
点击 **Nav2 Goal**，选择可达位置和终点朝向。

观察：
- 全局路径
- 局部控制
- /cmd_vel
- /amcl_pose

```bash
ros2 topic echo /cmd_vel
ros2 topic echo /amcl_pose
```

## 6. 三点测试
选择 A/B/C 三点，每次只发目标，不改代码。记录：
| Goal | Success | Collision | Time |
|---|---:|---:|---:|
